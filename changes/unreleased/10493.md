### Fixed

- A builtin model profile can run on your own provider. When the only provider serving a profile's model is one you declared in `models.json` (for example an API-key proxy serving `claude-opus-5-5`), Daily · Normal and the other builtin lanes now pick it instead of reporting that no model is available. The lane's own providers still come first, and gateways you never declared still never serve a builtin lane. Reported by 채완 ([#10485](https://github.com/code-yeongyu/oh-my-openagent/issues/10485), [#10493](https://github.com/code-yeongyu/oh-my-openagent/pull/10493)).
