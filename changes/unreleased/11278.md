**A session command OmO adds later is no longer sent to an attach-enforcing senpi host without an attachment.** The thread client fenced only a fixed list of mutations, while the host refuses every session command from an unattached connection except its read allowlist; under `SENPI_RPC_REQUIRE_ATTACH=1` any command missing from the client's list would be refused. The client now fences every session command except the reads the host exempts.
