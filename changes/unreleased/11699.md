**The memory tool can now repair a note that has no frontmatter.** `update_description` on a frontmatter-less note writes a frontmatter block holding only the new description and keeps the body byte-for-byte, instead of refusing with the same error as every other edit; the other edits still refuse, and their refusal now names `update_description` as the way to add frontmatter.
