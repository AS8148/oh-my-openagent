### Fixed

- The LSP tools now start the TypeScript language server without its syntax-only `tsserver` and `typingsInstaller` (#11755). A TypeScript session runs two processes instead of four (measured 292 MiB instead of 597 MiB on a small project). Set `initialization` for `typescript` in `lsp-client.json` to restore the old options; a builtin's defaults now reach `initialize` and user or project keys override them.
