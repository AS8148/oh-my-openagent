### Fixed

- A task child whose provider has no credential (for example `No API key found for openai.`) now counts as signed out: the walk skips that provider's other models and moves to the parent session's model instead of ending on the missing-key error. An expired session that only a fresh `/login` renews (for example Meta's `session expired (status 403)`) also counts as a credential failure, and so do the other ways senpi says a provider has no credential (a virtual model routed to a provider `which has no credentials`, compaction finding `no credentials resolved for provider`, a pinned Claude account that `is not configured, and account fallback is off`). An HTTP proxy asking for its own login (`Proxy Authentication Required (407)`) does not sign the provider out. A `/login` hint that is not about a missing credential (a Copilot endpoint refresh, a billing note, a model-scoped 403) no longer signs the provider out, and the final error says the credential is missing rather than rejected when none was found ([#11438](https://github.com/code-yeongyu/oh-my-openagent/pull/11438))
