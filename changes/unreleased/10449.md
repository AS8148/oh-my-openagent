**Only you can stop computer use with the stop chord on macOS and Linux X11.** A chord a program sends (the agent's own key presses, `xdotool`, another app posting key events) used to stop every session, and repeated, could keep computer use stopped; it is now ignored, while a press on a real keyboard still stops every running session at once. Wayland's shortcut portal cannot tell the two apart, and Windows follows in a separate change. ([#10444](https://github.com/code-yeongyu/oh-my-openagent/issues/10444), [#10449](https://github.com/code-yeongyu/oh-my-openagent/pull/10449))
