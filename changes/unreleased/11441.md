### Fixed

- `omo logout` now leaves a small sign-out note (no credentials, just the device and the time), so OmO Desktop can tell a deliberate sign-out from a credential store that hasn't answered yet. `omo account token` and `export` report it with exit code 10; exit 4 still means nothing could be read. Signing in again removes the note. ([#11441](https://github.com/code-yeongyu/oh-my-openagent/pull/11441), fixes [#11434](https://github.com/code-yeongyu/oh-my-openagent/issues/11434))
