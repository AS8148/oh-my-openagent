### Fixed

- `omo logout` now leaves a small sign-out note (no credentials, just the device and the time), so OmO Desktop can tell a deliberate sign-out from a credential store that hasn't answered yet. `omo account token` and `export` report it with exit code 10; exit 4 still means nothing could be read. Signing in again removes the note. The note is written before the credentials are removed, so a failed write leaves you signed in and `omo logout` reports the error; a damaged note is ignored (exit 4) and never breaks `omo account show`. ([#11441](https://github.com/code-yeongyu/oh-my-openagent/pull/11441), fixes [#11434](https://github.com/code-yeongyu/oh-my-openagent/issues/11434))
