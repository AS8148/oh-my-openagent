### Changed

- Each model family's current default is named once. Every builtin default, fallback rung, category gate, Claude Code alias and migration target that means "the newest Opus / Sonnet / Haiku / Fable / GPT / GLM / Kimi / Gemini" now reads its id from one table, so the next model bump is one edit. Resolved models stay the same, with one exception: the Claude Code `sonnet` alias now means the current Sonnet (`claude-sonnet-5-5`) instead of `claude-sonnet-4-6` ([#10141](https://github.com/code-yeongyu/oh-my-openagent/issues/10141), [#10483](https://github.com/code-yeongyu/oh-my-openagent/pull/10483)).
