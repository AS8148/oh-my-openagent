### Fixed

- After a restart or restore, the plan gate for plan-consultant / plan-reviewer is rebuilt from the session's own transcript instead of starting empty, so a lane that already asked for ulw-plan and wrote its plan can call plan-reviewer without asking again. Only user messages the engine recorded as typed (`inputSource` `interactive` or `rpc` on the session entry) count as a request; injected or unsourced input never does, and state handed over by a reload is kept (#10378).
