### Added

- Set `OMO_BUNDLED_SKILLS_DIR` to an absolute directory to share bundled skills
  across runtime installations. Absent or empty preserves existing behavior.
  Invalid directories raise a named configuration error. Conditional, user,
  project, and memory skill roots retain their existing locations.

## 2026-10-25 - Optional shared bundled skills directory (#11332)

Both bundled skill loaders use one resolver for `OMO_BUNDLED_SKILLS_DIR`.
The override replaces only `plugin/skills`; `plugin/skills-conditional`
remains relative to the plugin. Relative, missing, non-directory, and
unreadable values fail with `BundledSkillsDirectoryError`.
