### Fixed

- Bundled skills no longer ship `test`, `tests`, `__tests__`, or `*_test` folders nested below a skill's top level (such as ultimate-browsing's `engine/tests`), so a test module can no longer run inside the installed app and write caches there. Top-level `test/` and `tests/` resources still ship. ([#11377](https://github.com/code-yeongyu/oh-my-openagent/pull/11377), part of [#11373](https://github.com/code-yeongyu/oh-my-openagent/issues/11373))
