**Claude Fable 5.5 leads the Fable chains once released.** Once 5.5 is released, every builtin chain or profile that runs Claude Fable 5.1 tries 5.5 first at the same effort, with 5.1 kept as the next step. Until then no builtin default, chain or profile lists 5.5, so 5.1 keeps running ([#10798](https://github.com/code-yeongyu/oh-my-openagent/issues/10798), [#10800](https://github.com/code-yeongyu/oh-my-openagent/pull/10800)).

**Claude Fable 5.5 is recognised ahead of its launch.** Model detection, context limits, telemetry and the refusal fallback notice know Claude Fable 5.5. Until it is released, no routing path picks the provisional id without proof the model exists, and catalog data always wins over the launch placeholder ([#10798](https://github.com/code-yeongyu/oh-my-openagent/issues/10798), [#10800](https://github.com/code-yeongyu/oh-my-openagent/pull/10800)).
