### Added

- Computer use: the desktop engine's error vocabulary gains four codes for macOS shared-screen work, appended so every existing numeric code keeps its value: `UserIntervened` (-32024), `AxUnconfirmed` (-32025), `SpaceUnsupported` (-32026) and `SpaceMoveDenied` (-32027). The computer tool reports them as `COMPUTER_USER_INTERVENED`, `COMPUTER_AX_UNCONFIRMED`, `COMPUTER_SPACE_UNSUPPORTED` and `COMPUTER_SPACE_MOVE_DENIED`, each with a recovery hint. The protocol version is unchanged, and a host now keeps audit events whose code or action it does not know (as `unknown`) instead of dropping them. ([#11493](https://github.com/code-yeongyu/oh-my-openagent/pull/11493), part of [#11461](https://github.com/code-yeongyu/oh-my-openagent/issues/11461))
