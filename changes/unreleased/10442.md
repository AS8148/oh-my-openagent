**Computer use works on arm64 Linux and Windows.** Each OmO release now carries the desktop engine for Linux arm64 (glibc) and Windows arm64, built on native arm64 machines and checked with its self-test before upload. The compiled OmO binaries for those hosts include the engine, and an npm install downloads it on first use, where it used to report that no engine is built for the host. Musl Linux still has no engine. ([#10440](https://github.com/code-yeongyu/oh-my-openagent/issues/10440), [#10442](https://github.com/code-yeongyu/oh-my-openagent/pull/10442))
