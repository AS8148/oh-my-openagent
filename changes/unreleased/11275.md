**A summary queued by a session that named only its profile is judged with the account's home again.** Since #11202 a queued session summary is judged by the config it was recorded under; when that config named a profile but no home, the consent read had no home at all and fell back to the working directory. It now reads the account's home, as the send gate does. The reference doc also says that summaries queued before #11202 keep the old reading until they expire.
