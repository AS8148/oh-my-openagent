**OpenCode agents use the same model-specific prompt bodies as OmO Native.** The plugin builds each agent's model core with senpi's shared prompt builders, translates host tool names, and appends each agent's role explicitly, so every model in Native's catalog, Kimi K3.1 included, gets Native's prompt under OpenCode. Switching models also switches the prompt body without losing task mode or Hephaestus's model restriction. Session tool permissions are read once per session and then follow its update and delete events, and the OmO Native recommendation toast appears only in interactive launches and records each show. The prompt sent to the model lists each tool by a one-line snippet and carries no internal frame data.
