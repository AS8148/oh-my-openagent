### Fixed

- A ChatGPT subscription whose sign-in refresh fails only briefly at session start (connection refused, timeout, a 408/429/5xx from the token endpoint) now stays selected in the model profile. Before, the session moved to the next provider, for example a configured OpenAI API key, and stayed on that metered lane until it was restarted. A refused refresh still skips the provider with the re-authenticate notice ([#11442](https://github.com/code-yeongyu/oh-my-openagent/pull/11442), fixes [#11432](https://github.com/code-yeongyu/oh-my-openagent/issues/11432))
