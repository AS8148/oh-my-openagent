**The model capabilities cache is rewritten only when the catalog changed.** Each startup refresh fetched the models.dev catalog and rewrote `model-capabilities.json`, about 1.5 MB, even when the catalog was the same as the one on disk. The refresh now compares the fetched catalog with the file, ignoring the fetch timestamp, and skips the write when they match. `refresh-model-capabilities` follows the same rule, so after an unchanged refresh the file keeps the timestamp of the fetch that last changed it.
