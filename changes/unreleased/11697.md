### Fixed

- The Senpi side panel's git diff view now works when the user's shell exports `GIT_GLOB_PATHSPECS=1` or `GIT_ICASE_PATHSPECS=1`: the panel's diff reader no longer passes the global `--literal-pathspecs` flag, which git rejects as incompatible with those exported switches (exit 128). Tracked diffs and untracked-directory listings now carry per-pathspec `:(literal)` magic instead, which reaches git through the existing host `exec` with no environment change; `--no-index` diffs take plain filesystem paths, which need no pathspec handling. When `GIT_LITERAL_PATHSPECS=1` is exported, the paths stay bare instead, because that switch already turns literal matching on and would make git read the `:(literal)` prefix as part of the file name. ([#11697](https://github.com/code-yeongyu/oh-my-openagent/pull/11697), fixes [#11176](https://github.com/code-yeongyu/oh-my-openagent/issues/11176))
