### Fixed

- Native telemetry's OTLP output maps a model id outside the collector's pinned vocabulary to `custom`.
  Before, an unlisted id such as `claude-fable-5-5` passed through unchanged, and the collector rejected the
  record or span (`invalid_enum`). This covers every model key in the pin: `turn_completed` and its
  `omo.turn` span (`omo.model_id`, `gen_ai.request.model`, `gen_ai.response.model`), `session_started`
  `omo.default_model`, `kibitzer_summary` `omo.model_top`, the `category_config` `omo.cat_*` keys, and
  `session_summary` `omo.m1_model`..`omo.m3_model`, which keep `none`. (#11428)
- Native OTLP telemetry reads the client's session reasons, prompt suppression,
  category counts and delegation start reasons, filters those optional fields to
  the pinned collector vocabulary and bounds, and converts session-summary USD
  cost to rounded integer 1e-4 USD units. A start opted out in the persisted
  setting purges idle OTLP spool files without loading the exporter; an
  environment opt-out leaves the shared spool alone, and so does any running
  writer, which keeps an owner marker until it exits even when all of its
  batches are sealed. The purge is machine-wide: OTLP batches are one shared
  queue that any consented sender replays and carry no per-project scope, so
  once no writer is running a project-level opt-out also removes batches other
  projects left unsent. Legacy events and unsupported
  operating systems never initialize OTLP, transient startup failures retry
  after 60 seconds (a settled refusal is not retried), and OTLP deadlines no longer reject slow PostHog
  acknowledgements. ([#11431](https://github.com/code-yeongyu/oh-my-openagent/pull/11431))
