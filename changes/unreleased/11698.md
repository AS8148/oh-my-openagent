### Fixed

- The Senpi model-profile component's shared `models.json` parse can no longer be mutated through `readModelsJson`: the cached parse is deep-frozen before it is shared and the return type is deeply readonly, so a caller that writes into the returned value fails to typecheck and throws at runtime instead of silently changing what every other reader in the process sees. Cache behavior is unchanged. ([#11698](https://github.com/code-yeongyu/oh-my-openagent/pull/11698), fixes [#11034](https://github.com/code-yeongyu/oh-my-openagent/issues/11034))
