### Added

- In a Bun project (`bun.lock`, `bun.lockb`, `bunfig.toml`, or a `bun@` `packageManager`), `lsp_diagnostics` on a TypeScript directory typechecks it with `bun check`, and adds `bun lint` diagnostics when the installed bun has a linter. For a project that formats with prettier, the Senpi formatter runs `bun format` instead of the prettier binary when bun has it. Each command is used only after `bun <command> --help` exits 0 in an empty directory, and never when the project's own script of that name would run instead; every other project keeps the language-server path unchanged (#10840).
