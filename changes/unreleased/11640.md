### Fixed

- The SessionEnd cleanup launcher (`script/agent/cleanup-hook.sh`) accepted only `/tmp`, `/private/tmp` and `/var/folders` as log directories and silently rewrote anything else to `/tmp`, so on a host whose `TMPDIR` lives elsewhere the log was not where the caller expected it. It now accepts any absolute, existing temp directory outside the project tree, compares both paths physically so a symlinked `TMPDIR`, a symlinked project path or an unnormalised `//` or `/./` segment can no longer put the log inside the project, reports every rejected `TMPDIR` on stderr instead of substituting silently, and exposes the resolved path through `--print-log-file` so callers read one shared resolution (#10735).
- The first-party source scans use POSIX extended regular expressions instead of `git grep -P`, which exits 128 on a git built without USE_LIBPCRE (#10735).
