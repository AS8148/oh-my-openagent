**Windows Codex commands no longer stop at a command syntax error.** Generated command shims accept a quoted `NODE_REPL_NODE_PATH` in `config.toml` and also run when that setting or the config file is absent. Thanks to @fvegiard for the report and @LilMGenius for the fix.
