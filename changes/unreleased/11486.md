### Changed

- The memory file list in the prompt (`<external_projection>`) now shows every memory file name that carries a hint instead of hiding names behind `(+N more)`. Names drop `.md`, names sharing a date are grouped as `{a, b}-YYYYMMDD`, and hint-free runs (month chunks, timestamped runs, generated ids, id-named folders) fold into one readable entry. `memory.projection.max_entries_per_directory` now defaults to `0` (off) and `memory.projection.max_bytes` to `40960`. ([#11486](https://github.com/code-yeongyu/oh-my-openagent/pull/11486))
