**On Windows every session can now arm the stop chord, and only a key press on a real keyboard triggers it.** The chord used to be a `RegisterHotKey` registration, which only one process can hold: a second session's engine could not arm it, so its computer use refused input with `StopPathUnavailable`; and a chord a program sent (the agent's own key presses or any other app's `SendInput`) stopped computer use like a real press. A low-level keyboard hook now watches the chord in every session, ignores injected key events, and never swallows a key; one physical press stops every running session at once.
