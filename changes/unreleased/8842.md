**A `google/antigravity-gemini-3.1-pro` model in a fallback chain keeps its id.** Model resolution rewrote `gemini-3.1-pro` to `gemini-3.1-pro-preview` for the `google`, `github-copilot` and `vercel` providers without skipping the `antigravity-` form, so a user chain naming `antigravity-gemini-3.1-pro` could resolve to `antigravity-gemini-3.1-pro-preview`, an id Antigravity does not serve. The rewrite now skips it, the same way it already skipped `antigravity-gemini-3-flash`. A plain `gemini-3.1-pro` still becomes `gemini-3.1-pro-preview`. Thanks to @cynkai.
