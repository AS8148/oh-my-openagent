### Fixed

- Prometheus checks and executes the same authorized planning-file path, including relative symlink/`..` paths, aliased project roots, hashline renames, and patch moves. Patch headers must round-trip through the supported executor parser without changing authorized operations or targets. Rename/delete preserve named final links; content writes follow only allowed targets. Physical planning directories must be `.omo` directories strictly inside the real project, with filesystem-native casing. Nested plans and parent-folder Windows paths remain supported; required argument rewrites fail closed if the host's retained arguments cannot receive them ([#11424](https://github.com/code-yeongyu/oh-my-openagent/pull/11424))

### Security

- Known and not fixed here: a hard link already under `.omo` can share an inode with a file outside `.omo`; realpath does not provide inode isolation.
- Known and not fixed here: TOCTOU between `tool.execute.before` and the tool's open. Closing this race requires tool-side `O_NOFOLLOW` and directory-handle confinement.
