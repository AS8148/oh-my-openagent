### Fixed

- Prometheus checks and executes the same physical planning-file path, including relative symlink/`..` paths, hashline renames, and patch moves. Nested `.omo` directories and parent-folder Windows paths remain supported; patch headers include the #11392 parsing fix ([#11424](https://github.com/code-yeongyu/oh-my-openagent/pull/11424))

### Security

- Known and not fixed here: a hard link already under `.omo` can share an inode with a file outside `.omo`; realpath does not provide inode isolation.
- Known and not fixed here: TOCTOU between `tool.execute.before` and the tool's open. Closing this race requires tool-side `O_NOFOLLOW` and directory-handle confinement.
