**The telemetry collector now uses a private key for each installation.** Consented sessions register once with the collector and keep the install-bound key in a local 0600 cache; no shared ingest key is baked into the client. Registration failures disable only the collector branch for that process, rate-limit backoff persists across runs, and a rejected key is discarded for the next run. Explicit environment keys still take precedence, and PostHog delivery and opt-out rules are preserved.
